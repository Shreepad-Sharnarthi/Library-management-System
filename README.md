# 📚 Library Management System

A full-stack Library Management System built using React, Django REST Framework, and PostgreSQL.

## 🚀 Features

- JWT Authentication
- Dashboard
- Books Management (CRUD)
- Members Management (CRUD)
- Borrowings Management
- Reports
- REST APIs
- Responsive UI

## 🛠 Tech Stack

### Frontend
- React (Vite)
- Bootstrap 5
- Axios

### Backend
- Django
- Django REST Framework
- JWT Authentication

### Database
- PostgreSQL

## 📂 Project Structure

LibraryManagementSystem/
├── backend/
├── frontend/
└── docker-compose.yml

## ▶️ Run the Project

### Backend

```bash
cd backend
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
